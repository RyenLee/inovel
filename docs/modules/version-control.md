# 版本控制模块

## 1. 功能概述

版本控制模块基于 Git 实现，为小说项目提供完整的版本快照功能。包括创建快照、查看历史记录、恢复指定版本、版本对比（diff）等功能，支持自动记录每日修改。

## 2. 核心功能点

| 功能 | 描述 |
|------|------|
| 初始化 Git | 为项目初始化 Git 仓库 |
| 创建快照 | 创建 Git 提交记录 |
| 获取快照列表 | 查看版本历史 |
| 恢复快照 | 将项目恢复到指定版本 |
| 获取差异 | 查看两个版本之间的差异 |

## 3. API 参数说明

### 3.1 init_project_git - 初始化 Git

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |

### 3.2 create_snapshot - 创建快照

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |
| message | String | 否 | 快照描述信息 |

**返回结果：**

```json
{
  "hash": "a1b2c3d4",
  "message": "第一章完成",
  "timestamp": "2026-01-15T10:30:00Z"
}
```

### 3.3 get_snapshots - 获取快照列表

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |
| limit | i32 | 否 | 返回数量限制（默认 50） |

**返回结果：**

```json
[
  {
    "hash": "a1b2c3d4",
    "message": "第一章完成",
    "timestamp": "2026-01-15T10:30:00Z",
    "author": "Author"
  },
  {
    "hash": "e5f6g7h8",
    "message": "添加第二章",
    "timestamp": "2026-01-14T15:20:00Z",
    "author": "Author"
  }
]
```

### 3.4 restore_snapshot - 恢复快照

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |
| hash | String | 是 | 快照哈希值 |

### 3.5 get_snapshot_diff - 获取差异

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |
| hash | String | 是 | 快照哈希值 |

**返回结果：** 标准 diff 格式字符串

## 4. Gitignore 规则

项目 Git 仓库默认忽略以下文件：

```
*.encrypted
*.tmp
.DS_Store
Thumbs.db
```

## 5. 业务规则

### 5.1 自动快照
- 每日首次打开项目时自动创建快照
- 仅在有变更时创建

### 5.2 快照消息
- 支持自定义提交信息
- 默认消息格式：`Auto snapshot - {日期}`

### 5.3 恢复规则
- 恢复前自动创建当前状态的快照
- 防止恢复操作导致数据丢失

## 6. 异常处理

| 错误场景 | 错误信息 | 处理方式 |
|----------|----------|----------|
| Git 未初始化 | "Git 仓库未初始化" | 返回错误 |
| 快照不存在 | "快照不存在: {hash}" | 返回错误 |
| 恢复失败 | "恢复快照失败: {e}" | 返回错误 |
| 项目路径无效 | "项目路径无效" | 返回错误 |
