# 模板系统模块

## 1. 功能概述

模板系统为作者提供预设和自定义的文本模板功能，包括内置模板和用户模板两类。支持分类管理、预览和快速插入到编辑器中，提高写作效率。

## 2. 核心功能点

| 功能 | 描述 |
|------|------|
| 获取内置模板 | 获取所有预设的系统模板 |
| 获取用户模板 | 获取当前项目用户的自定义模板 |
| 获取全部模板 | 同时获取内置和用户模板 |
| 创建用户模板 | 创建新的用户自定义模板 |
| 更新用户模板 | 修改用户模板内容 |
| 删除用户模板 | 删除用户模板 |

## 3. API 参数说明

### 3.1 get_builtin_templates - 获取内置模板

**请求参数：** 无

**返回结果：** `WritingTemplate[]`

### 3.2 get_user_templates - 获取用户模板

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |

**返回结果：** `UserTemplate[]`

### 3.3 get_all_templates - 获取全部模板

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |

**返回结果：** `[WritingTemplate[], UserTemplate[]]`

### 3.4 save_user_template - 创建用户模板

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| params | CreateUserTemplateParams | 是 | 创建参数 |

**CreateUserTemplateParams 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| project_id | i64 | 是 | 项目 ID |
| name | String | 是 | 模板名称 |
| description | String | 否 | 模板描述 |
| category | String | 否 | 分类标签 |
| content | String | 是 | 模板内容 |

### 3.5 update_user_template - 更新用户模板

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| template_id | i64 | 是 | 模板 ID |
| params | UpdateUserTemplateParams | 是 | 更新参数 |

**UpdateUserTemplateParams 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | String | 否 | 模板名称 |
| description | String | 否 | 模板描述 |
| category | String | 否 | 分类标签 |
| content | String | 否 | 模板内容 |

### 3.6 delete_user_template - 删除用户模板

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| template_id | i64 | 是 | 模板 ID |

## 4. 数据结构

### 4.1 WritingTemplate 内置模板结构

```json
{
  "id": "builtin_1",
  "name": "章节开头",
  "description": "标准章节开头模板",
  "category": "章节",
  "content": "【第一章 标题】\n\n"
}
```

### 4.2 UserTemplate 用户模板结构

```json
{
  "id": 1,
  "project_id": 100,
  "name": "我的模板",
  "description": "自定义章节模板",
  "category": "章节",
  "content": "===================\n",
  "created_at": "2026-01-01T00:00:00Z",
  "updated_at": "2026-01-01T00:00:00Z"
}
```

## 5. 业务规则

### 5.1 内置模板
- 存储在 `builtin_templates.json` 文件中
- 不可修改、不可删除
- 全局所有项目共享

### 5.2 用户模板
- 存储在项目数据库中
- 按项目隔离
- 支持 CRUD 操作

### 5.3 模板分类
- 支持自定义分类标签
- 分类用于模板筛选和分组展示

## 6. 异常处理

| 错误场景 | 错误信息 | 处理方式 |
|----------|----------|----------|
| 模板不存在 | "模板不存在" | 返回错误 |
| 项目不存在 | "项目不存在" | 返回错误 |
| 名称重复 | "模板名称已存在" | 返回错误 |
| 数据库错误 | "数据库操作失败: {e}" | 返回错误 |

- 显示模板列表（支持分类筛选）
