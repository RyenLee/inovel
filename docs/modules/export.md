# 导出功能模块

## 1. 功能概述

导出功能模块支持将小说项目导出为多种格式，包括纯文本（TXT）、Markdown、HTML（适合打印）和 EPUB 电子书格式。导出时会按照卷/章节结构组织内容。

## 2. 核心功能点

| 功能          | 描述                               |
| ------------- | ---------------------------------- |
| 导出 TXT      | 导出为纯文本格式                   |
| 导出 Markdown | 导出为 Markdown 格式               |
| 获取导出内容  | 获取 Markdown 格式的完整内容字符串 |
| 导出 HTML     | 导出为 HTML 格式（适合打印）       |
| 导出 EPUB     | 导出为 EPUB 电子书格式             |
| 获取导出目录  | 获取导出文件存储目录               |
| 打开导出目录  | 在文件管理器中打开导出目录         |

## 4. 导出格式说明

### 4.1 TXT 格式

- 纯文本输出
- 章节之间用空行分隔
- 无任何格式标记

### 4.2 Markdown 格式

- 保留章节标题层级（# ## ###）
- 保留加粗、斜体等基本格式
- 生成目录索引

### 4.3 HTML 格式

- 适合浏览器打印成 PDF
- 包含基础样式
- 响应式布局

### 4.4 EPUB 格式

- 标准电子书格式
- 包含元数据（书名、作者）
- 支持阅读器阅读

## 5. 业务规则

### 5.1 文件命名

- 导出文件命名格式：`{项目名}_{格式}_{日期}.{扩展名}`
- 示例：`我的小说_txt_20260115.txt`

### 5.2 导出目录

- 导出文件存储在 `{APP_DATA}/exports/{project_id}/` 目录

### 5.3 内容顺序

- 按卷的排序顺序导出
- 同卷内按章节排序顺序导出

## 6. 异常处理

| 错误场景      | 错误信息             | 处理方式 |
| ------------- | -------------------- | -------- |
| 项目不存在    | "项目不存在"         | 返回错误 |

| 文件写入失败  | "写入文件失败: {e}"  | 返回错误 |
| EPUB 生成失败 | "EPUB 生成失败: {e}" | 返回错误 |
