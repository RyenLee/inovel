# 名称生成模块

## 1. 功能概述

名称生成模块为作者提供随机生成中英文人名和地名等功能，帮助作者在创作时快速生成多样化的角色名称和地点名称。

## 2. 核心功能点

| 功能 | 描述 |
|------|------|
| 生成随机名称 | 根据分类和性别生成随机名称 |

## 3. API 参数说明

### 3.1 generate_names - 生成随机名称

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| category | String | 是 | 名称分类 |
| gender | Option<String> | 否 | 性别（可选值：`"male"`、`"female"`、`null`） |
| count | u32 | 是 | 生成数量 |

**category 可选值：**

| 值 | 描述 |
|------|------|
| `chinese_name` | 中文姓名 |
| `english_name` | 英文姓名 |
| `chinese_place` | 中文地名 |
| `english_place` | 英文地名 |

**返回结果：** `String[]` 名称列表

## 4. 使用示例

### 4.1 生成中文姓名

```json
{
  "category": "chinese_name",
  "gender": null,
  "count": 5
}
```

**返回结果：**

```json
["李明", "王芳", "张伟", "刘洋", "陈静"]
```

### 4.2 生成英文姓名（男性）

```json
{
  "category": "english_name",
  "gender": "male",
  "count": 3
}
```

**返回结果：**

```json
["James Wilson", "Robert Brown", "Michael Davis"]
```

### 4.3 生成中文地名

```json
{
  "category": "chinese_place",
  "gender": null,
  "count": 4
}
```

**返回结果：**

```json
["青云山", "东海郡", "长安城", "西域"]
```

## 5. 数据来源

名称数据存储在 `src-tauri/resources/names.json` 文件中，包含：
- 中文姓氏列表
- 中文名字列表（按性别分类）
- 英文名字列表（按性别分类）
- 英文姓氏列表
- 中文地名后缀（如 "山"、"城"、"郡"）
- 英文地名词汇

## 6. 业务规则

### 6.1 生成规则
- 中文姓名 = 随机姓氏 + 随机名字
- 英文姓名 = 随机英文名 + 随机姓氏
- 性别为 null 时，混合使用男女名字

### 6.2 数量限制
- 单次最大生成数量：100
- 超出限制时返回空列表

## 7. 异常处理

| 错误场景 | 错误信息 | 处理方式 |
|----------|----------|----------|
| 无效分类 | - | 返回空列表 |
| 数量超限 | - | 返回空列表 |
| 性别无效 | - | 忽略性别参数 |
