# 项目管理模块

## 1. 功能概述

项目管理模块负责 inovel 应用中小说项目的基本操作，包括项目的创建、打开、删除、更新、迁移等功能。该模块是整个应用的核心入口，所有创作活动都围绕项目展开。

## 2. 核心功能点

| 功能 | 描述 |
|------|------|
| 创建项目 | 创建新的小说项目，初始化项目目录和数据库 |
| 获取最近项目 | 分页获取最近打开的项目列表 |
| 打开项目 | 打开指定项目，验证路径有效性 |
| 更新项目 | 更新项目的基本信息（名称、作者、描述） |
| 删除项目 | 从列表中移除项目，可选择是否删除文件 |
| 设置封面 | 为项目设置封面图片 |
| 项目迁移 | 自动检测并迁移旧格式项目到新格式 |
| 窗口大小 | 保存/获取项目的窗口大小设置 |

## 3. 详细操作流程

### 3.1 创建项目

```
用户输入项目信息 → 验证路径 → 创建目录结构 → 初始化 Git 仓库 → 保存到数据库 → 返回项目元数据
```

### 3.2 打开项目

```
传入项目 ID → 查询数据库 → 验证项目路径 → 检查加密状态 → 返回项目元数据
```

### 3.3 项目迁移

```
检测旧格式项目 → 复制到新目录 → 转换数据格式 → 验证完整性 → 更新数据库记录
```

## 4. API 参数说明

### 4.1 create_project - 创建项目

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| params | CreateProjectParams | 是 | 创建参数对象 |

**CreateProjectParams 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | String | 是 | 项目名称（书名） |
| author | String | 是 | 作者名 |
| description | String | 否 | 项目描述 |
| path | String | 是 | 项目存储父目录 |

**返回结果：**

```json
{
  "id": 1,
  "project_id": "P7K3M9",
  "name": "我的小说",
  "author": "作者名",
  "description": "项目描述",
  "path": "/path/to/project",
  "created_at": "2026-01-01T00:00:00Z",
  "updated_at": "2026-01-01T00:00:00Z",
  "is_valid": true,
  "cover_path": null,
  "encrypted": false
}
```

### 4.2 get_recent_projects - 获取最近项目

**请求参数：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | i32 | 否 | 1 | 页码（从1开始） |
| page_size | i32 | 否 | 10 | 每页项目数 |

**返回结果：**

```json
{
  "items": [...],
  "total": 25,
  "page": 1,
  "page_size": 10,
  "total_pages": 3
}
```

### 4.3 open_project - 打开项目

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | i64 | 是 | 项目数据库 ID |

**返回结果：** `ProjectMeta` 对象

### 4.4 update_project - 更新项目

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | i64 | 是 | 项目数据库 ID |
| params | UpdateProjectParams | 是 | 更新参数对象 |

**UpdateProjectParams 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | String | 是 | 项目名称 |
| author | String | 是 | 作者名 |
| description | String | 是 | 项目描述 |

### 4.5 remove_project_from_list - 删除项目

**请求参数：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| id | i64 | 是 | - | 项目数据库 ID |
| keep_files | bool | 否 | true | 是否保留项目文件 |

### 4.6 set_cover - 设置封面

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | i64 | 是 | 项目数据库 ID |
| image_path | String | 是 | 封面图片路径 |

### 4.7 check_migration_needed - 检测迁移

**返回结果：** 待迁移项目数量 `i32`

### 4.8 migrate_existing_projects - 执行迁移

**请求参数：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| dry_run | bool | 否 | false | 是否仅执行试运行 |

**返回结果：**

```json
{
  "migrated_count": 5,
  "failed_count": 0,
  "total_count": 5,
  "details": [
    {
      "project_id": "P7K3M9",
      "old_path": "/old/path",
      "new_path": "/new/path",
      "success": true,
      "error": null
    }
  ]
}
```

## 5. 业务规则

### 5.1 项目标识符生成规则
- 格式：`P` + 5位字母数字组合
- 示例：`P7K3M9`、`PABC12`
- 确保全局唯一性

### 5.2 项目路径规则
- 存储路径 = 配置的根目录 + 项目唯一标识符
- 示例：`{APP_DATA}/projects/P7K3M9/`

### 5.3 删除操作规则
- `keep_files = true`：仅从列表移除，保留文件
- `keep_files = false`：同时删除项目目录和所有文件

### 5.4 迁移规则
- 仅迁移格式不兼容的旧项目
- 迁移前自动创建备份
- 支持 dry_run 模式预览迁移结果

## 6. 异常处理

| 错误场景 | 错误信息 | 处理方式 |
|----------|----------|----------|
| 路径无效 | "项目路径失效：{path}" | 返回 is_valid=false |
| 数据库错误 | "数据库连接失败: {e}" | 返回错误信息 |
| 目录创建失败 | "创建项目目录失败: {e}" | 回滚并返回错误 |
| 项目不存在 | "项目不存在" | 返回 404 错误 |
| 迁移失败 | "迁移失败: {details}" | 记录详情，继续处理其他项目 |
