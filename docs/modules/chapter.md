# 章节管理模块

## 1. 功能概述

章节管理模块负责小说项目中卷（Volume）和章节（Chapter）的完整生命周期管理，包括创建、读取、更新、删除、排序、移动等操作。章节内容以 Markdown 文件形式存储在项目目录中。

## 2. 核心功能点

| 功能         | 描述                               |
| ------------ | ---------------------------------- |
| 创建卷       | 在项目下创建新的卷                 |
| 创建章节     | 在指定卷下创建新章节               |
| 获取章节树   | 获取项目的完整卷/章节树形结构      |
| 更新卷名     | 修改卷的名称                       |
| 更新章节标题 | 修改章节标题                       |
| 更新章节摘要 | 修改章节摘要/简介                  |
| 更新章节字数 | 更新章节字数统计缓存               |
| 更新章节状态 | 修改章节状态（草稿/已完成/已发布） |
| 删除卷       | 删除卷及其包含的所有章节文件       |
| 删除章节     | 删除章节文件                       |
| 排序卷       | 拖拽调整卷的排列顺序               |
| 排序章节     | 拖拽调整同卷内章节的排列顺序       |
| 移动章节     | 将章节移动到其他卷                 |
| 保存图片     | 上传并保存图片到项目媒体目录       |
| 获取章节内容 | 读取章节的 Markdown 内容           |
| 保存章节内容 | 保存章节的 Markdown 内容           |

## 3. 详细操作流程

### 3.1 创建卷

```
输入卷名 → 验证项目存在 → 获取最大排序号 → 创建卷记录 → 返回卷信息
```

### 3.2 创建章节

```
选择目标卷 → 输入章节标题 → 可选输入初始内容 → 获取排序号 → 创建 Markdown 文件 → 创建数据库记录 → 返回章节信息
```

### 3.3 删除卷

```
确认删除 → 删除卷下所有章节文件 → 删除章节数据库记录 → 删除卷数据库记录
```

### 3.4 拖拽排序

```
用户拖拽 → 计算新的排序位置 → 更新数据库排序号 → 更新界面
```

## 4. API 参数说明

### 4.1 create_volume - 创建卷

| 参数名     | 类型   | 必填 | 说明          |
| ---------- | ------ | ---- | ------------- |
| project_id | i64    | 是   | 项目数据库 ID |
| name       | String | 是   | 卷名称        |

**返回结果：** `Volume` 对象

### 4.2 create_chapter - 创建章节

| 参数名          | 类型           | 必填 | 说明               |
| --------------- | -------------- | ---- | ------------------ |
| project_id      | i64            | 是   | 项目数据库 ID      |
| volume_id       | i64            | 是   | 所属卷 ID          |
| title           | String         | 是   | 章节标题           |
| initial_content | Option<String> | 否   | 初始 Markdown 内容 |

**返回结果：** `Chapter` 对象

### 4.3 get_chapter_tree - 获取章节树

| 参数名     | 类型 | 必填 | 说明          |
| ---------- | ---- | ---- | ------------- |
| project_id | i64  | 是   | 项目数据库 ID |

**返回结果：** `VolumeWithChapters[]` 数组

### 4.4 update_volume_name - 更新卷名

| 参数名    | 类型   | 必填 | 说明        |
| --------- | ------ | ---- | ----------- |
| volume_id | i64    | 是   | 卷数据库 ID |
| new_name  | String | 是   | 新的卷名称  |

### 4.5 update_chapter_title - 更新章节标题

| 参数名     | 类型   | 必填 | 说明          |
| ---------- | ------ | ---- | ------------- |
| chapter_id | i64    | 是   | 章节数据库 ID |
| new_title  | String | 是   | 新标题        |

### 4.6 update_chapter_word_count - 更新章节字数

| 参数名     | 类型 | 必填 | 说明          |
| ---------- | ---- | ---- | ------------- |
| chapter_id | i64  | 是   | 章节数据库 ID |
| word_count | i32  | 是   | 字数          |

### 4.7 update_chapter_summary - 更新章节摘要

| 参数名      | 类型   | 必填 | 说明          |
| ----------- | ------ | ---- | ------------- |
| chapter_id  | i64    | 是   | 章节数据库 ID |
| new_summary | String | 是   | 新摘要        |

### 4.8 reorder_volumes - 排序卷

| 参数名      | 类型     | 必填 | 说明                       |
| ----------- | -------- | ---- | -------------------------- |
| project_id  | i64      | 是   | 项目数据库 ID              |
| ordered_ids | Vec<i64> | 是   | 卷 ID 列表（按新顺序排列） |

### 4.9 reorder_chapters - 排序章节

| 参数名      | 类型     | 必填 | 说明                         |
| ----------- | -------- | ---- | ---------------------------- |
| volume_id   | i64      | 是   | 所属卷 ID                    |
| ordered_ids | Vec<i64> | 是   | 章节 ID 列表（按新顺序排列） |

### 4.10 move_chapter_to_volume - 移动章节

| 参数名           | 类型 | 必填 | 说明                 |
| ---------------- | ---- | ---- | -------------------- |
| chapter_id       | i64  | 是   | 章节数据库 ID        |
| target_volume_id | i64  | 是   | 目标卷 ID            |
| sort_order       | i32  | 是   | 在目标卷中的排序位置 |

### 4.11 delete_volume - 删除卷

| 参数名    | 类型 | 必填 | 说明        |
| --------- | ---- | ---- | ----------- |
| volume_id | i64  | 是   | 卷数据库 ID |

### 4.12 delete_chapter - 删除章节

| 参数名     | 类型 | 必填 | 默认值 | 说明          |
| ---------- | ---- | ---- | ------ | ------------- |
| chapter_id | i64  | 是   | -      | 章节数据库 ID |
| keep_file  | bool | 否   | false  | 是否保留文件  |

### 4.13 save_image - 保存图片

| 参数名     | 类型   | 必填 | 说明                  |
| ---------- | ------ | ---- | --------------------- |
| project_id | i64    | 是   | 项目数据库 ID         |
| file_name  | String | 是   | 文件名                |
| file_data  | String | 是   | Base64 编码的文件数据 |

**返回结果：** 相对路径字符串（如 `"media/1234567890_12345.png"`）

## 5. 数据结构

### 5.1 Volume 卷结构

```json
{
  "id": 1,
  "project_id": 100,
  "name": "第一卷",
  "sort_order": 0
}
```

### 5.2 Chapter 章节结构

```json
{
  "id": 1,
  "volume_id": 1,
  "title": "第一章",
  "file_path": "chapters/v1_ch1.md",
  "sort_order": 0,
  "summary": "章节简介...",
  "word_count_cache": 2500,
  "status": "draft",
  "created_at": "2026-01-01T00:00:00Z",
  "updated_at": "2026-01-01T00:00:00Z"
}
```

### 5.3 VolumeWithChapters 卷及其章节

```json
{
  "id": 1,
  "project_id": 100,
  "name": "第一卷",
  "sort_order": 0,
  "chapters": [
    {
      /* Chapter 对象 */
    },
    {
      /* Chapter 对象 */
    }
  ]
}
```

## 6. 业务规则

### 6.1 文件存储规则

- 章节文件存储在 `{project_path}/chapters/` 目录
- 文件命名格式：`{卷序号}_{章节序号}_{标题}.md`
- 图片文件存储在 `{project_path}/media/` 目录

### 6.2 排序规则

- `sort_order` 数值越小越靠前
- 新创建的项目/卷自动获取最大 sort_order + 1

### 6.3 删除规则

- 删除卷时会同时删除其下所有章节文件
- `keep_file = true` 时仅删除数据库记录，保留文件

### 6.4 章节状态

- `draft` - 草稿
- `completed` - 已完成
- `published` - 已发布

## 7. 异常处理

| 错误场景     | 错误信息                | 处理方式 |
| ------------ | ----------------------- | -------- |
| 卷不存在     | "卷不存在"              | 返回错误 |
| 章节不存在   | "章节不存在"            | 返回错误 |
| 项目不存在   | "项目不存在"            | 返回错误 |
| 文件删除失败 | "删除章节文件失败: {e}" | 返回错误 |
| 数据库错误   | "数据库操作失败: {e}"   | 返回错误 |
