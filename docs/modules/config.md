# 配置管理模块

## 1. 功能概述

配置管理模块负责应用全局配置的读取、修改、导入导出和热加载。支持配置历史记录和回滚功能，采用 TOML 格式存储配置文件。

## 2. 核心功能点

| 功能 | 描述 |
|------|------|
| 获取完整配置 | 获取全部配置项 |
| 按分类获取配置 | 按分类获取配置项列表 |
| 获取单个配置值 | 获取指定配置项的值 |
| 设置单个配置值 | 更新单个配置项 |
| 批量设置配置值 | 批量更新多个配置项 |
| 重置配置 | 重置为默认配置 |
| 重新加载配置 | 从磁盘重新加载配置 |
| 导出配置 | 导出配置到 TOML 文件 |
| 导入配置 | 从 TOML 文件导入配置 |
| 获取配置历史 | 查看配置修改历史 |
| 回滚配置 | 回滚到历史版本 |

## 3. API 参数说明

### 3.1 get_config - 获取完整配置

**请求参数：** 无

**返回结果：** `AppConfig` 完整配置对象

### 3.2 get_config_by_category - 按分类获取

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| category | String | 是 | 配置分类名称 |

**返回结果：** `ConfigItem[]`

### 3.3 get_config_value - 获取单个值

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| key | String | 是 | 配置键名（支持点号路径，如 `app.version`） |

### 3.4 set_config_value - 设置单个值

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| key | String | 是 | 配置键名 |
| value | String | 是 | 配置值 |
| encrypted | bool | 否 | 是否加密存储 |

### 3.5 set_config_values - 批量设置

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| values | HashMap<String, String> | 是 | 配置键值对 |

### 3.6 reload_config - 重新加载

**请求参数：** 无

### 3.7 export_config - 导出配置

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| path | String | 是 | 导出文件路径 |

### 3.8 import_config - 导入配置

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| path | String | 是 | 导入文件路径 |

### 3.9 reset_config - 重置配置

**请求参数：** 无

### 3.10 get_config_history - 获取历史

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | usize | 是 | 页码 |
| page_size | usize | 否 | 每页数量 |

### 3.11 rollback_config - 回滚

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| history_id | String | 是 | 历史记录 ID |

## 5. 业务规则

### 5.1 配置热加载
- 修改配置后自动热加载
- 无需重启应用

### 5.2 配置历史
- 记录最近 100 条配置修改
- 支持按时间回滚

### 5.3 配置加密
- 敏感配置（如 API Key）支持加密存储
- 加密配置自动解密返回前端

### 5.4 默认值
- 首次运行自动创建默认配置
- 支持一键重置为默认值

## 6. 异常处理

| 错误场景 | 错误信息 | 处理方式 |
|----------|----------|----------|
| 配置文件不存在 | "配置文件不存在" | 创建默认配置 |
| 解析失败 | "TOML 解析失败: {e}" | 返回错误 |
| 无效键名 | "无效的配置键: {key}" | 返回错误 |
| 写入失败 | "写入配置失败: {e}" | 返回错误 |
| 回滚失败 | "回滚失败: {e}" | 返回错误 |
