# 加密功能模块

## 1. 功能概述

加密功能模块为小说项目提供 AES-256 加密保护，支持项目加密和解密、密码验证、密码修改等功能。同时支持全局加密设置，保护整个应用程序的敏感数据。

## 2. 核心功能点

### 2.1 项目加密

| 功能 | 描述 |
|------|------|
| 加密项目 | 使用 AES-256 加密项目内容 |
| 解密项目 | 输入密码解密项目 |
| 验证密码 | 验证项目密码是否正确 |
| 修改密码 | 修改项目加密密码 |
| 重新加密 | 关闭项目时重新加密 |
| 检查加密状态 | 判断项目是否已加密 |

### 2.2 全局加密

| 功能 | 描述 |
|------|------|
| 获取全局加密状态 | 检查全局加密是否启用 |
| 启用全局加密 | 为应用程序启用全局加密 |
| 禁用全局加密 | 关闭全局加密 |
| 修改全局密码 | 修改全局加密密码 |
| 验证全局密码 | 验证全局密码是否正确 |

### 2.3 国际化

| 功能 | 描述 |
|------|------|
| 获取语言列表 | 获取支持的语言列表 |
| 获取当前语言 | 获取当前设置的 locale |
| 设置语言 | 设置应用程序语言 |

## 3. API 参数说明

### 3.1 encrypt_project - 加密项目

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| params | EncryptProjectParams | 是 | 加密参数 |

**EncryptProjectParams 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| project_path | String | 是 | 项目路径 |
| password | String | 是 | 密码 |
| confirm_password | String | 是 | 确认密码 |

### 3.2 decrypt_project - 解密项目

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| params | DecryptProjectParams | 是 | 解密参数 |

**DecryptProjectParams 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| project_path | String | 是 | 项目路径 |
| password | String | 是 | 密码 |

**返回结果：** 解密后的项目路径

### 3.3 verify_project_password - 验证项目密码

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_path | String | 是 | 项目路径 |
| password | String | 是 | 密码 |

**返回结果：** `true` 或 `false`

### 3.4 change_project_password - 修改项目密码

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| params | ChangePasswordParams | 是 | 密码修改参数 |

**ChangePasswordParams 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| project_path | String | 是 | 项目路径 |
| old_password | String | 是 | 旧密码 |
| new_password | String | 是 | 新密码 |
| confirm_password | String | 是 | 确认新密码 |

### 3.5 reencrypt_project - 重新加密

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_path | String | 是 | 项目路径 |
| password | String | 是 | 密码 |

### 3.6 is_project_encrypted_command - 检查加密状态

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_path | String | 是 | 项目路径 |

**返回结果：** `true` 表示已加密，`false` 表示未加密

## 4. 加密算法说明

### 4.1 AES-256 加密
- 对称加密算法
- 256 位密钥长度
- 用于加密项目文件内容

### 4.2 密钥派生
- 使用 PBKDF2 算法
- 从密码派生加密密钥
- 随机盐值防暴力破解

## 5. 业务规则

### 5.1 密码规则
- 密码最小长度：6 字符
- 新密码与确认密码必须一致
- 修改密码时需验证旧密码

### 5.2 加密文件
- 加密后文件扩展名为 `.encrypted`
- 原始文件在加密后删除
- 解密后恢复原始文件

### 5.3 全局加密
- 影响应用程序级别的敏感数据
- 需要单独设置密码
- 与项目加密互不影响

## 6. 异常处理

| 错误场景 | 错误信息 | 处理方式 |
|----------|----------|----------|
| 密码错误 | "密码错误" | 返回 false |
| 密码不匹配 | "两次输入的密码不一致" | 返回错误 |
| 项目已加密 | "项目已加密" | 返回错误 |
| 项目未加密 | "项目未加密" | 返回错误 |
| 加密失败 | "加密失败: {e}" | 返回错误 |
| 解密失败 | "解密失败: {e}" | 返回错误 |
