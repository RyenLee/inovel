# 写作工具模块

## 1. 功能概述

写作工具模块为作者提供全方位的写作辅助功能，包括写作目标管理、字数统计追踪、番茄钟专注计时、敏感词检测等功能，帮助作者提升写作效率和专注度。

## 2. 核心功能点

### 2.1 写作目标

| 功能         | 描述                       |
| ------------ | -------------------------- |
| 获取写作目标 | 获取项目的每日写作目标设置 |
| 保存写作目标 | 设置或更新每日写作目标     |
| 字数记录     | 记录每日写作字数           |
| 今日字数     | 获取今日已写字数           |

### 2.2 字数统计

| 功能         | 描述                       |
| ------------ | -------------------------- |
| 获取写作统计 | 按日期范围获取写作字数记录 |
| 字数趋势     | 统计每日/每周/每月字数变化 |
| 项目统计     | 统计项目的总字数           |

### 2.3 番茄钟

| 功能         | 描述                   |
| ------------ | ---------------------- |
| 记录专注会话 | 记录一次专注番茄钟     |
| 获取专注会话 | 获取历史专注会话列表   |
| 获取专注统计 | 统计专注时长、完成率等 |

### 2.4 敏感词

| 功能       | 描述                         |
| ---------- | ---------------------------- |
| 添加敏感词 | 向词库添加单个敏感词         |
| 移除敏感词 | 从词库移除敏感词             |
| 列出敏感词 | 获取项目的敏感词列表         |
| 导入敏感词 | 批量从文件导入敏感词         |
| 扫描敏感词 | 在文本中检测敏感词并返回位置 |

## 3. API 参数说明

### 3.1 写作目标

#### get_writing_goal - 获取写作目标

| 参数名     | 类型 | 必填 | 说明    |
| ---------- | ---- | ---- | ------- |
| project_id | i64  | 是   | 项目 ID |

**返回结果：**

```json
{
  "project_id": 100,
  "daily_goal": 3000,
  "enabled": true
}
```

#### save_writing_goal - 保存写作目标

| 参数名     | 类型 | 必填 | 说明         |
| ---------- | ---- | ---- | ------------ |
| project_id | i64  | 是   | 项目 ID      |
| daily_goal | i32  | 是   | 每日目标字数 |
| enabled    | bool | 是   | 是否启用目标 |

### 3.2 字数统计

#### get_writing_stats - 获取写作统计

| 参数名     | 类型   | 必填 | 说明                   |
| ---------- | ------ | ---- | ---------------------- |
| project_id | i64    | 是   | 项目 ID                |
| start_date | String | 是   | 开始日期（YYYY-MM-DD） |
| end_date   | String | 是   | 结束日期（YYYY-MM-DD） |

**返回结果：**

```json
[
  {
    "date": "2026-01-01",
    "words_written": 2500,
    "target": 3000
  },
  {
    "date": "2026-01-02",
    "words_written": 3200,
    "target": 3000
  }
]
```

#### upsert_writing_record - 记录写作

| 参数名        | 类型   | 必填 | 说明               |
| ------------- | ------ | ---- | ------------------ |
| project_id    | i64    | 是   | 项目 ID            |
| date          | String | 是   | 日期（YYYY-MM-DD） |
| words_written | i32    | 是   | 写作字数           |

#### get_today_words - 获取今日字数

| 参数名     | 类型 | 必填 | 说明    |
| ---------- | ---- | ---- | ------- |
| project_id | i64  | 是   | 项目 ID |

**返回结果：**

```json
{
  "date": "2026-01-15",
  "words_written": 1500,
  "target": 3000,
  "goal_reached": false
}
```

### 3.3 番茄钟

#### record_focus_session - 记录专注会话

| 参数名           | 类型   | 必填 | 说明                           |
| ---------------- | ------ | ---- | ------------------------------ |
| project_id       | i64    | 是   | 项目 ID                        |
| session_type     | String | 是   | 会话类型（"focus" 或 "break"） |
| duration_minutes | i32    | 是   | 时长（分钟）                   |
| started_at       | String | 是   | 开始时间（RFC3339）            |

#### get_focus_sessions - 获取专注会话列表

| 参数名     | 类型   | 必填 | 说明     |
| ---------- | ------ | ---- | -------- |
| project_id | i64    | 是   | 项目 ID  |
| start_date | String | 否   | 开始日期 |
| end_date   | String | 否   | 结束日期 |

**返回结果：**

```json
[
  {
    "id": 1,
    "project_id": 100,
    "session_type": "focus",
    "duration_minutes": 25,
    "started_at": "2026-01-15T09:00:00Z",
    "completed": true
  }
]
```

#### get_focus_stats - 获取专注统计

| 参数名     | 类型 | 必填 | 说明    |
| ---------- | ---- | ---- | ------- |
| project_id | i64  | 是   | 项目 ID |

**返回结果：**

```json
{
  "total_sessions": 50,
  "total_minutes": 1250,
  "completed_sessions": 45,
  "completion_rate": 0.9
}
```

### 3.4 敏感词

#### add_sensitive_word - 添加敏感词

| 参数名     | 类型   | 必填 | 说明    |
| ---------- | ------ | ---- | ------- |
| project_id | i64    | 是   | 项目 ID |
| word       | String | 是   | 敏感词  |

#### remove_sensitive_word - 移除敏感词

| 参数名     | 类型   | 必填 | 说明    |
| ---------- | ------ | ---- | ------- |
| project_id | i64    | 是   | 项目 ID |
| word       | String | 是   | 敏感词  |

#### list_sensitive_words - 列出敏感词

| 参数名     | 类型 | 必填 | 说明    |
| ---------- | ---- | ---- | ------- |
| project_id | i64  | 是   | 项目 ID |

**返回结果：** `String[]` 敏感词列表

#### import_sensitive_words - 导入敏感词

| 参数名     | 类型   | 必填 | 说明                   |
| ---------- | ------ | ---- | ---------------------- |
| project_id | i64    | 是   | 项目 ID                |
| file_path  | String | 是   | 文件路径（每行一个词） |

**返回结果：** 成功导入的数量

#### scan_sensitive_words - 扫描敏感词

| 参数名     | 类型   | 必填 | 说明       |
| ---------- | ------ | ---- | ---------- |
| project_id | i64    | 是   | 项目 ID    |
| content    | String | 是   | 待扫描文本 |

**返回结果：**

```json
[
  {
    "word": "敏感词",
    "start": 10,
    "end": 14
  }
]
```

## 4. 业务规则

### 4.1 写作目标规则

- 每日目标单位为字数
- 目标可随时启用/禁用
- 记录按日期去重，后面的记录覆盖前面的

### 4.2 番茄钟规则

- `session_type` 可选值：`focus`（专注）、`break`（休息）
- `completed` 标记会话是否完成
- 默认专注时长为 25 分钟

### 4.3 敏感词规则

- 敏感词匹配为精确匹配
- 扫描返回所有匹配的位置信息
- 支持批量导入，每行一个词

## 5. 异常处理

| 错误场景   | 错误信息               | 处理方式 |
| ---------- | ---------------------- | -------- |
| 项目不存在 | "项目不存在"           | 返回错误 |
| 数据库错误 | "数据库操作失败: {e}"  | 返回错误 |
| 文件不存在 | "文件不存在: {path}"   | 返回错误 |
| 参数无效   | "无效的参数: {detail}" | 返回错误 |
