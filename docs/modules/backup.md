# 备份功能模块

## 1. 功能概述

备份功能模块为小说项目提供完整的数据备份和恢复能力。支持手动全量备份和增量备份两种模式，备份文件存储为 ZIP 格式，方便迁移和归档。

## 2. 核心功能点

| 功能 | 描述 |
|------|------|
| 全量备份 | 将整个项目打包为 ZIP 文件 |
| 增量备份 | 仅备份自上次备份以来变更的文件 |
| 列出备份 | 查看项目的所有备份记录 |
| 获取备份日志 | 查看备份操作的详细日志 |
| 恢复备份 | 从 ZIP 备份文件恢复项目 |
| 删除备份记录 | 删除备份记录（保留或删除文件） |
| 获取备份统计 | 获取备份统计信息 |

## 3. API 参数说明

### 3.1 backup_project - 全量备份

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| app_handle | AppHandle | 是 | Tauri 应用句柄 |
| project_id | i64 | 是 | 项目 ID |

**返回结果：**

```json
{
  "id": 1,
  "project_id": 100,
  "backup_type": "full",
  "file_path": "/path/to/backup.zip",
  "size_bytes": 1048576,
  "created_at": "2026-01-15T10:00:00Z"
}
```

### 3.2 create_incremental_backup - 增量备份

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| app_handle | AppHandle | 是 | Tauri 应用句柄 |
| project_id | i64 | 是 | 项目 ID |

**返回结果：** `BackupRecord` 对象

### 3.3 list_backups - 列出备份

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |

**返回结果：** `BackupRecord[]`

### 3.4 get_backup_logs - 获取备份日志

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |
| start_index | i32 | 否 | 开始索引 |

**返回结果：**

```json
[
  {
    "timestamp": "2026-01-15T10:00:00Z",
    "level": "info",
    "message": "备份完成",
    "details": "files: 25, size: 1.2MB"
  }
]
```

### 3.5 restore_backup - 恢复备份

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |
| backup_id | i64 | 是 | 备份记录 ID |

### 3.6 delete_backup_record - 删除备份记录

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |
| backup_id | i64 | 是 | 备份记录 ID |
| delete_file | bool | 否 | 是否同时删除备份文件 |

### 3.7 get_backup_stats - 获取备份统计

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| project_id | i64 | 是 | 项目 ID |

**返回结果：**

```json
{
  "total_backups": 10,
  "total_size_bytes": 10485760,
  "last_backup_at": "2026-01-15T10:00:00Z"
}
```

## 4. 数据结构

### 4.1 BackupRecord 备份记录

```json
{
  "id": 1,
  "project_id": 100,
  "backup_type": "full",
  "file_path": "/path/to/backup.zip",

  "notes": "手动备份",
  "created_at": "2026-01-15T10:00:00Z"
}
```

## 5. 备份类型说明

### 5.1 全量备份 (full)
- 打包整个项目目录
- 包含所有文件和文件夹
- 适合首次备份或重要节点备份

### 5.2 增量备份 (incremental)
- 仅打包自上次备份以来修改的文件
- 通过比较文件修改时间判断变更
- 节省存储空间，适合频繁备份

## 6. 业务规则

### 6.1 备份文件命名
- 格式：`{项目ID}_{备份类型}_{日期时间}.zip`
- 示例：`100_full_20260115_100000.zip`

### 6.2 备份目录
- 存储在 `{APP_DATA}/backups/{project_id}/` 目录

### 6.3 恢复规则
- 恢复前自动创建当前状态的备份
- 解压覆盖现有文件
- 恢复完成后验证文件完整性

## 7. 异常处理

| 错误场景 | 错误信息 | 处理方式 |
|----------|----------|----------|
| 项目不存在 | "项目不存在" | 返回错误 |
| 备份文件不存在 | "备份文件不存在" | 返回错误 |
| 解压失败 | "解压失败: {e}" | 返回错误 |
| 磁盘空间不足 | "磁盘空间不足" | 返回错误 |
| 数据库错误 | "数据库操作失败: {e}" | 返回错误 |
