### 4.2 代码验证

- `useEditor.ts` 已正确导入 `DecorationSet`（第7行）

- 章节切换时调用 `rescanSensitive`（第240-247行）

**后端 API 验证：**
- `scan_sensitive_words` 命令已正确注册（lib.rs 第130行）
- 使用 Aho-Corasick 算法进行高效多模式匹配
- 返回结果包含 `word`、`start`、`end` 字段，与前端接口一致
